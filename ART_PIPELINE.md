# Little Captain's Hat: Art Pipeline

**For hand-drawn replacements (since 0.105b), start at
[art_replacements/README_START_HERE.md](art_replacements/README_START_HERE.md)**:
the Sprite Workshop. Drop a PNG under the file name its folder's
`manifest.csv` gives, and the game uses it instead of its own art, no code
needed (details: `SPRITE_WORKSHOP_REPORT.md`).

The art instructions now live in the developer guides, which are kept up to date
with each iteration:

- [DEV_GUIDES/VESSEL_ART.md](DEV_GUIDES/VESSEL_ART.md): decks, cabins, sails,
  slots, visual profiles, templates (the former content of this file);
- [DEV_GUIDES/COMPANION_ANIMATION.md](DEV_GUIDES/COMPANION_ANIMATION.md): the
  ship's cat (the owner's pose images) and later the dog;
- [DEV_GUIDES/SPRITES.md](DEV_GUIDES/SPRITES.md): general rules for any sprite;
- [DEV_GUIDES/README.md](DEV_GUIDES/README.md): the index.

This file is kept so that older links still work.
